# trustScoreCard

A Trust Score display card: a circular score gauge, a tier badge (High / Moderate / Low),
per-category verification badges (Address, Face, Category, Virtual Inspection), and a
score breakdown by category.

Open `index.html` in a browser to view the showcase — three examples across the High
(70–100), Moderate (40–69), and Low (0–39) trust tiers.

## Files

- `index.html` — showcase page, renders the three example cards
- `style.css` — design tokens and component styles
- `trust-score-card.js` — builds a card element from a data object (score, name, role, badge states, breakdown)
